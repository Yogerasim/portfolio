# Trains

Trains is an iOS application built with Swift and UIKit for searching railway routes from point A to point B using the Yandex Schedule API.

## Overview
The project loads timetable and route data from the API, processes the response, and displays it in the user interface.
It is focused on networking, decoding, search flows, and building a clean iOS app structure.

## Features
- railway route search
- integration with Yandex Schedule API
- network requests and JSON decoding
- displaying results in iOS interface
- user search flow from point A to point B
- app architecture practice

## Tech Stack
- Swift
- UIKit
- MVVM
- URLSession
- REST API
- JSON Decoding
- Networking
- iOS app architecture

## Goals
- practice real API integration
- improve data processing and UI rendering
- strengthen architecture and mobile product thinking
- build a useful transport-related iOS application
